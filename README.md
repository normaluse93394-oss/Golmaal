# Golmaal

A Flutter starter for a WhatsApp-style messaging UI with original branding.

## Run

1. Install Flutter and Android Studio.
2. Run `flutter create .` inside this folder if platform folders are missing.
3. Run `flutter pub get`.
4. Run `flutter run`.

## Current version

- Golmaal home/chat/status/profile UI
- Local demo messages
- Message composer
- Material 3 design

## Next step

Connect Firebase Authentication, Cloud Firestore, Storage and FCM for real accounts,
real-time messages, media, groups and notifications. Firebase credentials are intentionally
not included in this starter.
